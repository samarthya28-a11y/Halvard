## Not demonstrated (so not claimed)

- A real browser, proxy or endpoint hook that sees AI prompts. The device hook contract stands in; a user who types into an unmanaged browser on an unmanaged machine is not seen.
- A real agent framework. The gateway and the tools are reference models written by the same author; integration with a real agent SDK or tool protocol (and its identity) is unbuilt.
- Detection of injected text. The gateway reasons about behaviour (untrusted context then a sensitive action); an injection that makes the agent do something the rules allow is not stopped.
- Vendor behaviour. Whether an AI vendor trains on inputs is what the customer attests; Halvard does not verify it. The sample catalog is fictional.
- A real canary callback service, real file servers, Active Directory honey objects, decoy rotation.
- Tripwires add early warning; they do not replace the detector, and a program that avoids them is not stopped by them.
- An agent case's impact currently uses its owner's reach in the graph (the agent acts for them); it does not yet use the agent identity's own permissions.
- Everything in the earlier phases' 'Not demonstrated' lists still applies.
