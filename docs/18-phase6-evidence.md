## Not demonstrated (so not claimed)

- Real vulnerability data. The feed is synthetic (`HLV-SAMPLE-*`); a production tenant imports a real feed, which is not built.
- A real inventory collector on Windows, macOS or Linux. The reference host reports the software and settings a test sets, and device health after an update is a signal a test sets.
- Update download, signing and staging; maintenance windows for rollouts; scheduling.
- A real network scan. The 'internet' is a reference model. The ownership challenge, scope refusal and probe contents are real logic against that model.
- Backup immutability and restore tests as inputs to the Restore score (F092); the score says they are not measured.
- The weights, thresholds and deadlines are Halvard defaults, not derived from data; the score is not a benchmark against other companies and not a forecast.
- Framework mappings (SOC 2, ISO 27001, NIS2, HIPAA, PCI DSS, GDPR, DPDP) and the insurer packet (F101, F102). No certification is claimed.
- Persistence of Glass state beyond the process (the Ledger holds history; the live state is in memory in this build).
